About PotatoGen

GitHub CDN Link Generator

PotatoGen generates candidate CDN links for files hosted in public GitHub repositories.

Repository mode retrieves file paths using GitHub's public API. Links are not guaranteed to work unless the underlying files and provider endpoints are available.

Results are paginated to keep the interface responsive.
