Surge Publisher

Publish your chosen GitHub file at new Surge root URLs.

For online publishing, deploy render-surge.yaml as a separate Render Blueprint. Set SURGE_TOKEN privately in Render. Paste that service's HTTPS URL above and its MONSTERDROP_SURGE_KEY as the connection key. Keep this tab open during batches; your computer's terminal can stay closed when using the online server. For local publishing, use the localhost URL and the code printed by the helper.

Creates public deployments. HTML and SVG files from public repositories are supported; sites requiring a build must be built first.

When the batch ends, published links are automatically attached in Discord channel 1501072686921683034. Failed deployments are excluded; inconclusive HTTP checks are listed separately. Set DISCORD_BOT_TOKEN privately in the Surge publisher's Render environment to enable delivery.
