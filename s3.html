How Amazon S3 Links Work

This generator uses MonsterDrop's Amazon S3 URL format: https://BUCKET.s3.amazonaws.com/PATH. It does not upload or copy files from GitHub to Amazon S3. The object must already exist in the specified bucket and be publicly accessible.
