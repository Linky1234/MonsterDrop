How Conversion Works

HTML → SVG: Places HTML inside an SVG foreignObject. It is a wrapper, not a pixel-perfect vector conversion.

SVG → HTML: Embeds the SVG markup inside a complete HTML document.

Both conversions are performed locally. External CSS, images, scripts, and relative file paths are not bundled. Some SVG viewers will not display embedded HTML.
